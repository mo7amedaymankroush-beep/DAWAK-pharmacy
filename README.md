# DAWAK - دواك

واجهة تجريبية لمتجر صيدلية مبنية باستخدام React وVite.

## تشغيل الواجهة وواجهة الطلبات

1. ثبّت Node.js (نسخة LTS) من https://nodejs.org
2. ثبّت MySQL وأنشئ قاعدة البيانات:

```bash
CREATE DATABASE dawak_pharmacy CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

3. انسخ `.env.example` إلى `.env` واضبط بيانات MySQL ورمزًا طويلًا خاصًا بلوحة الصيدلية.
	لتفعيل الحسابات، اضبط `AUTH_TOKEN_SECRET` (32 حرفًا عشوائيًا على الأقل) وبيانات MySQL. يتيح التسجيل البريد الإلكتروني أو رقم الهاتف مع كلمة مرور؛ يرسل الخادم رسالة ترحيب SMS للحسابات المسجلة برقم هاتف عند ضبط بيانات Twilio. لتسجيل الدخول السريع، أنشئ OAuth credentials في Google وFacebook واضبط `APP_ORIGIN` و`GOOGLE_CLIENT_ID` و`GOOGLE_CLIENT_SECRET` و`GOOGLE_CALLBACK_URL` و`FACEBOOK_APP_ID` و`FACEBOOK_APP_SECRET` و`FACEBOOK_CALLBACK_URL`. سجّل رابطَي callback كما هما في `.env.example` ضمن إعدادات كل مزوّد. في الإنتاج استخدم HTTPS وحدّث روابط الرجوع و`APP_ORIGIN` إلى نطاق الموقع الفعلي.
4. ثبّت الحزم:

```bash
npm install
```

5. شغّل الخادم في Terminal:

```bash
npm run server
```

6. شغّل الواجهة في Terminal آخر:

```bash
npm run dev
```

7. افتح رابط Vite، غالبًا `http://localhost:5173`.

ينشئ الخادم جدولي `orders` و`order_items` تلقائيًا عند أول اتصال. يتم حفظ الطلب وعناصره في معاملة واحدة، والأسعار والرسوم يعاد حسابها على الخادم. رسوم التوصيل الافتراضية 30 ج.م والخصم 0؛ يمكن ضبطهما عبر `DELIVERY_FEE` و`DISCOUNT_PERCENT` في `.env`.

ينشئ الخادم أيضًا جدول `customer_accounts` ويحدّث مخطط الحسابات القديمة تلقائيًا. التسجيل التقليدي يقبل البريد أو الهاتف مع كلمة مرور مخزنة بتجزئة آمنة؛ الحساب الهاتفي يستقبل رسالة ترحيب إذا كانت Twilio معدّة. تسجيل الدخول التقليدي يقبل البريد أو الهاتف وكلمة المرور. Google/Facebook يحتاجان مفاتيح OAuth وروابط callback صحيحة. جلسات الحساب موقعة وتنتهي بعد 30 يومًا.

لوحة الصيدلي: افتح `http://localhost:5173/#pharmacist` وأدخل قيمة `PHARMACY_ADMIN_TOKEN`. تتطلب واجهة الطلبات رمزًا صالحًا، ويمكن للصيدلي تغيير حالة الطلب. لا تضع ملف `.env` في Git.

## الملفات المهمة

- `src/App.jsx`: مكونات الواجهة والتفاعلات البسيطة.
- `src/index.css`: الألوان والتنسيقات والتجاوب مع الموبايل.
- `public/dawak-logo.jpg`: صورة اللوجو التي وفّرها المستخدم.

## ملاحظات

- البحث والتصنيفات تعمل من بيانات تجريبية داخل التطبيق. السلة تحفظ معرّفات المنتجات والكميات في `localStorage`.
- تأكيد الشراء يرسل بيانات العميل ومعرّفات المنتجات والكميات إلى الخادم؛ الخادم هو مصدر السعر النهائي ويخزن الطلب في MySQL ليظهر في لوحة الصيدلي.
- رفع الروشتة يسمح باختيار صورة أو PDF، لكنه لا يرسلها إلى خادم.
- لوحة الصيدلي تستخدم رمزًا إداريًا مشتركًا. قبل النشر الفعلي، استبدله بنظام حسابات وصلاحيات للمستخدمين وسجلات تدقيق.
- تأكيد الطلب يتطلب تشغيل MySQL والخادم وإعداد `.env` كما سبق. تسجيل الحساب وإرسال الروشتة ما زالا يحتاجان تكاملًا مستقلًا.
- المنتجات والأسعار الحالية أمثلة تجريبية؛ راجعها قبل استخدام الموقع فعليًا.
